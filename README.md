# Claims Verification System

This project is a **Claims Verification System** for managing and approving lecturer claims, including hours worked, hourly rates, and additional documentation uploads. The application provides an interface for verifying, approving, and rejecting claims and allows users to upload supporting documents.

---

## Features

- **Lecturer Claims Submission**: Lecturers can submit claims for hours worked, hourly rates, and attach supporting documents.
- **Pending Claims Verification**: Coordinators and managers can view, approve, or reject pending claims.
- **Document Upload and Display**: Lecturers can upload supporting documents, which are displayed in the claim details.
- **Dynamic Calculations**: Automatic calculation of total claim amounts based on hours worked and hourly rates.
- **Responsive Design**: The UI is built with Bootstrap to ensure responsiveness across devices.

---

## Technologies

- **ASP.NET Core MVC**: Backend framework used for creating the web application.
- **Entity Framework Core**: ORM for database interaction.
- **Bootstrap**: For responsive front-end design.
- **C#**: Core programming language for the application logic.
